What Changed, and Why It Matters

A detailed comparison of the main branch and the validation branch of the ACR cardiac imaging analysis

Geographic Disparities in ACR-Accredited Cardiac Imaging Across the United States  ·  Generated 2026-08-07  ·  7 commits  ·  Validation gate 124 → 156 checks

Read this first — the one-paragraph version. The original analysis was sound in its methods but was quietly losing data. A lookup table used to convert facility postal codes into counties was the wrong one: it was six years out of date and covered a slightly different kind of postal code. Because of that, 96 accredited imaging facilities never reached the dataset, and the entire state of Connecticut showed up as having zero cardiac imaging capacity when it actually has 32 accredited facilities. Separately, a statistical setting was left at its software default rather than being estimated from the data. Fixing both recovered every missing facility and changed one of the paper's conclusions. The paper's main finding — that accredited cardiac imaging is overwhelmingly concentrated in cities — was not affected and is now on firmer ground.

2. The four problems that were found

Problem 1 — Facilities were being lost in the postal-code lookup

In plain English. Every imaging facility in the source data has a postal (ZIP) code, not a county. To count facilities per county, the analysis needs a translation table from ZIP codes to counties. The project brief specified a particular table published by the US Department of Housing and Urban Development (HUD), updated for early 2026. That table was never obtained — it needs a free access key — so a different, older table from the Census Bureau was substituted. The substitute has two blind spots. It does not cover postal codes used only for PO boxes and large institutions such as hospitals, and it was built before Connecticut reorganised its counties. As a result, 96 facilities simply disappeared, with no error message.

Technical detail. The substitute was the Census 2020 ZCTA-to-county relationship file, which maps ZIP Code Tabulation Areas rather than ZIP codes, and assigned multi-county ZIPs by largest land area rather than by largest residential-address share as the brief required. The correct HUD file is now fetched by code/01c_fetch_hud_crosswalk.py, which reads an API token from an environment variable or a git-ignored file, retries transient failures, and refuses to write a crosswalk unless it is nationally complete and Connecticut resolves to current geography.

Result. All 2,264 eligible facility records now map to a valid county. Nothing is dropped silently: every record is either included or given a written reason for exclusion, recorded in data/processed/facility_mapping_audit.csv.

Problem 2 — Connecticut had vanished entirely

In plain English. In 2022 Connecticut abolished its eight counties and replaced them with nine "planning regions". The old lookup table still used the retired county codes. The rest of the analysis used the new codes. The two never matched, so every Connecticut facility fell through the gap. The published figures showed 1.6 million adults in Connecticut with no accredited cardiac imaging at all, which is simply untrue.

Technical detail. The 2020 file emits FIPS codes 09001–09015; the county universe from TIGER 2023 uses 09110–09190. There is no overlap, so a left join produced silent nulls. The HUD Q1 2026 crosswalk returns the planning regions directly, so no special-case handling is needed in production. A permanent regression test asserts that all 32 Connecticut records resolve.

Problem 3 — A statistical setting was left at its default

In plain English. Counting models need a setting that describes how "spread out" the counts are. Think of it as a dial. The original analysis left the dial at the software's factory position of 1.0 instead of measuring where it should sit for this data. Measured properly, it sits near 0.2 to 0.6. Because the dial was set too high, the analysis was more cautious than the data warrant, and one real association was reported as absent.

Technical detail. The models used NegativeBinomial(alpha=1.0), a fixed-dispersion GLM. The project brief asked for the dispersion parameter to be reported, which implies estimating it. Estimating it by maximum likelihood gives lower AIC and lower BIC in every model and outcome combination. The primary specification is now NB2 with dispersion estimated, defined once in code/model_spec.py so no script can drift. Fixed alpha = 1.0 is retained and reported as a labelled sensitivity analysis.

Why this was not chosen to get a better P value. The decision rests on the project brief and on model fit (AIC and BIC), both of which point the same way and were settled before looking at which conclusions moved. The fixed-alpha results are still published alongside, so any reader can see both.

Problem 4 — The self-check could only catch half of the errors

In plain English. The project has an automatic checker that compares every number in the paper against the data. It reported "0 mismatches", which sounded reassuring. But it only asked "is the correct number present somewhere?" It never asked "is an old, wrong number also still present?" Eight outdated figures were sitting in the paper while the checker reported a clean bill of health.

Technical detail. ck_prose used a substring search over the whole document, which is a one-sided test. The gate now also carries a FORBIDDEN list of obsolete values and phrases and fails if any appear. It grew from 124 checks to 156.

The one conclusion that changed. Social vulnerability and cardiac CT capacity. Before, this looked like no relationship. Now it is a modest positive association: more accredited CT capacity in more vulnerable counties, not less. Both the recovered facilities and the corrected statistical setting contributed. 6. New safeguards

In plain English. The point of this work was not only to fix the numbers but to make the same class of mistake impossible to repeat quietly. Four things now stand in the way.
SafeguardWhat it prevents
Full audit trailEvery source record is accounted for. A facility can no longer disappear without a written reason.
Two-sided self-checkThe gate fails if an obsolete number or sentence is still in the paper, not just if a current one is missing.
No fabricated dataA missing input file used to be replaced with random numbers that looked plausible. Production now stops with an error; demo behaviour requires an explicit flag.
One definition of the modelThe statistical specification lives in a single file. Scripts cannot quietly disagree about what "primary" means, which is exactly what had happened.

7. What did not change

The paper's central finding stands. Accredited cardiac imaging is overwhelmingly concentrated in metropolitan counties — 98.1% of cardiac MR capacity and 92.5% of cardiac CT capacity — and metropolitan status remains by far the strongest geographic correlate, with roughly eightfold higher cardiac MR capacity. That result was unchanged by every correction, and it now rests on a complete dataset rather than one missing 96 facilities. The methodological conclusion — that deprivation indices should not be used as proxies for imaging access without adjusting for rurality — also stands, and the external-index validation supports it.

8. Glossary

TermPlain meaning
Accredited facilityA site formally certified by the American College of Radiology to perform the scan to a defined quality standard.
CMR / CCTCardiac MRI and cardiac CT — two advanced heart-imaging tests.
FIPS codeThe five-digit federal identifier for a county.
CrosswalkA translation table, here from postal ZIP codes to counties.
SVISocial Vulnerability Index — a CDC measure combining poverty, housing, transport, disability and other factors.
EDIEconomic Deprivation Index — a purpose-built measure created for this study from six economic indicators.
SDISocial Deprivation Index — an independent published measure, used to check the findings were not an artefact of the purpose-built one.
IRRIncidence rate ratio. 1.00 = no difference; 1.03 = 3% more capacity per step; 0.95 = 5% less.
95% confidence intervalThe range of values consistent with the data. If it excludes 1.00, the finding is called statistically significant.
Dispersion (alpha)How variable the counts are relative to a simple model. Estimating it correctly matters for the width of the confidence intervals.
AIC / BICScores that compare competing models. Lower is better.
MonotonicMoving in one direction without reversing. The deprivation pattern is not monotonic, which is why the wording changed.
NENot estimable — a number that genuinely cannot be calculated from so few events, reported honestly instead of guessed.
