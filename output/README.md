# Output Directory Guide

Everything in this folder is generated. Nothing here is edited by hand, and
every file has a named generator in `code/`. All of it rebuilds from the
committed data:

```bash
python code/00_run_all.py --with-present
```

If a file here ever disagrees with the manuscript, the generated file is
correct and the manuscript needs fixing. That rule exists because an earlier
submission carried two numbers that had been transcribed by hand from a
narrative document no script produced. That document has been removed.

---

## Start here if you are reviewing the analysis

### `validation/` — the paper checked against the data

| File | What it is |
|---|---|
| `manuscript_check.txt` | The manuscript checked against the data: named values, table cells, wording claims, forbidden obsolete values, and every quoted estimate. It states the number of checks and mismatches |
| `manuscript_numbers.txt` | Every number the paper quotes, recomputed and formatted for reading |
| `manuscript_numbers.json` | The same values at full precision, plus model diagnostics |

Generated by `code/12_manuscript_numbers.py`. The JSON also carries a
`model_diagnostics` block with outcome overdispersion, estimated-dispersion
negative binomial versus Poisson AIC for the eight SVI and EDI models, and
sensitivity to fixing the dispersion parameter, all on the primary sample. See `docs/REPRODUCIBILITY.md` for how to read it.

### `results/` — model results, machine-readable

| File | What it is |
|---|---|
| `index_comparison_results.json` | Every model estimate at full precision: the SVI, the purpose-built EDI, and the external Graham Center SDI, each unadjusted and adjusted for metropolitan status. Also the SVI–EDI and SDI–EDI correlations and each index's association with rurality |
| `index_comparison_results.txt` | The same results formatted for reading |

Generated by `code/09_validated_index_sdi.py`. Figures 1B and 2 are drawn from
the generated results, so a plotted value and a reported value cannot drift
apart. The revision analyses are in `reviewer_analyses.json` (from
`code/18_reviewer_analyses.py`).

> **Read estimates from the JSON, not the `.txt`.** The text file prints three
> decimal places for readability. Rounding a 3-dp value again to 2 dp gives the
> wrong answer for some estimates — the SVI-adjusted CMR lower bound is
> 0.954948, which is 0.95, but reads as 0.955 in the text file and rounds a
> second time to 0.96. The manuscript and figures round once, from full
> precision.

### `tables/`

| File | Role | Generator |
|---|---|---|
| `Table1_Capacity_by_Rurality_and_EDI.*` | Manuscript Table 1 | `17_table1.py` |
| `Table4_Population_Characteristics.*` | Manuscript Table 4, characteristics of county residents (the CSV is read by the revision script) | `20_table4_population.py` |

| `table1_descriptive.csv`, `table1_formatted.txt` | Descriptive table from stage B | `03_descriptive_analysis.py` |

**Manuscript Tables 2 and 3 live in the manuscript file itself**, and Tables 1
and 4 are also written here by their generators; the manuscript copies are what
`12_manuscript_numbers.py` checks cell by cell. Hand-made `.docx` copies of the
other tables used to sit here; they were removed because no script generated them
and they had gone stale, still carrying the retired "ADI" label and
pre-adjustment estimates.
