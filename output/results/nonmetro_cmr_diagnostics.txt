==============================================================================
R2-03  WHY THE NONMETROPOLITAN CMR ESTIMATE HAD NO CONFIDENCE INTERVAL
==============================================================================

Stratum: 1,956 nonmetropolitan counties, 14 accredited CMR facilities,
each in a different county (counts: {'0': 1942, '1': 14}).

Primary specification (NB2, dispersion estimated), as originally fitted:
  optimiser reported converged = True
  score at the stopping point: const 1.18e-02, idx10 -9.80e-03, alpha -5.76e-01
  estimated alpha = 0.003951
  eigenvalues of the negated Hessian = [-0.0755, 4.1151, 244.3423]
  log-likelihood NB2 = -60.0503; Poisson (alpha = 0) = -60.0480

Diagnosis:
  The negated Hessian has a negative eigenvalue, so it is not positive
  definite. statsmodels inverts it only when it is, and otherwise returns no
  standard errors; the confidence interval and P value were therefore
  missing. The cause is the dispersion parameter. With every county holding
  zero or one facility there is no overdispersion to estimate, the likelihood
  is maximised at the boundary alpha = 0, and the optimiser stopped just
  inside it. The Poisson log-likelihood is higher than the NB2 value at that
  point, which confirms the boundary maximum.

  At alpha = 0 the NB2 model is the Poisson model, so the maximum-likelihood
  NB2 fit is the Poisson fit, whose information matrix is well conditioned:

  Poisson Wald          IRR 0.70 (0.56-0.89), P 0.003
  Profile likelihood    95% CI 0.55-0.88, LR P 0.001
  Robust (HC0)          IRR 0.70 (0.60-0.83), P <0.001
  Pearson dispersion    0.251 (no overdispersion)

  Holding alpha fixed instead of estimating it barely moves the estimate:
    alpha = 1e-06  IRR 0.70 (0.56-0.89), P 0.003
    alpha = 0.1    IRR 0.70 (0.56-0.89), P 0.003
    alpha = 0.5    IRR 0.70 (0.56-0.89), P 0.003
    alpha = 1.0    IRR 0.71 (0.56-0.89), P 0.004

  Interaction model, all 3,134 counties, NB2 with alpha estimated from all

    metropolitan EDI slope    1.00 (0.97-1.04), P 0.863
